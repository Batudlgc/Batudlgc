### What I've built

**[Munich First 90](https://munichfirst90.com)** — a live guide to the first 90 days of German bureaucracy for international students in Munich.
- 11 core steps (Anmeldung, bank, health insurance, residence permit …) in dependency order, each linked to its official source
- English · Deutsch · Türkçe
- *Ask*: an LLM (Mistral) answers only from the site's own sourced content and cites the step it used. Requests for individual legal advice are declined, which keeps the product within the German Legal Services Act (RDG).
- React Native (Expo) · TypeScript · tests + CI · progress stays on the device, no accounts

**[qlab](https://github.com/Batudlgc/qlab)** — a quant research framework built so that the validation layer comes before the strategy layer.
- Embargoed walk-forward, locked holdout, mandatory transaction costs, logged trials, deflated Sharpe
- Point-in-time universes and survivorship checks, plus a limit-order-book simulator
- Main lesson so far: across 66 momentum configurations the best out-of-sample Sharpe of 0.91 deflates to 0.05 once you count the trials
